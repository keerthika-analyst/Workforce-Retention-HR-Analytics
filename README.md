# Workforce Retention & HR Analytics

## Project Overview
This project focuses on analyzing workforce data to understand employee retention, attrition, attendance, performance, engagement, promotions, training, and salary trends.

## Objectives
- Analyze employee workforce details.
- Identify employee attrition trends.
- Monitor attendance and leave patterns.
- Evaluate employee performance and engagement.
- Analyze promotions and training activities.
- Identify employees at risk of leaving.

## Tools & Technologies
- SQL
- Power BI
- Microsoft Excel

## Project Files
- `Workforce retention & HR analysis.sql` – SQL queries and analysis.
- `Workforce_Retentions_SQL_Documentation.docx` – SQL documentation.
- `workforce_retention.pbix` – Power BI dashboard.
- `Workforce_Retention_PowerBI_documentation.docx` – Power BI documentation.
